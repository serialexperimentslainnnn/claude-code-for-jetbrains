## What lives here

The JVM half of the test pyramid, in **one Gradle `test` task**. That is not a stylistic choice: the IntelliJ
Platform Gradle plugin instruments only that task with the platform runtime, so a hand-rolled `Test` task
would not have `Project` on its classpath and the headless and integration layers would not run at all.

Three layers share this tree, and they are told apart by directory, not by name.

## Layers

| Layer | Where | What it is |
|---|---|---|
| **Unit** | `protocol/` · `permission/` · `diff/` · `process/` · `settings/` · `session/` · `context/` · `git/` · `ui/` | Plain JVM. No platform runtime, no `Project`. The bulk of the suite. |
| **Headless component** | `headless/` | `BasePlatformTestCase`, in-process: real services, a real `Project`, a real settings store. |
| **Integration** | `integration/` | A real `ClaudeSession` driven against the deterministic `bin/fake-claude` stand-in with JSONL fixtures. |
| **Drift** | `drift/` | The protocol surface: every subtype the plugin knows, including the ones it deliberately never sends. |

**Contract tests are the layer that catches what compiles and still breaks at runtime**, and they live beside
the code they constrain rather than in a directory of their own. `ReachabilityContractTest` sits at the top
level because its subject is the whole of `src/main`.

| Contract | What it refuses to let happen |
|---|---|
| `ReachabilityContractTest` | A declaration nothing in `src/main` names. **The repository's signature defect**: implemented, tested and unreachable. |
| `JcefDependencyContractTest` | Using `com.intellij.ui.jcef` without declaring it hard, at a full build number. Mutation-checked. |
| `InitOrderContractTest` | A property declared below the `init` block that uses it — **in a top-level class body only**. The scan keys on a four-space indent, so the same defect inside a nested class is not pinned. |
| `NoFileDeletionContractTest` | The plugin deleting a file it has no business deleting. |
| `GitReadOnlyContractTest` · `GitApiContractTest` · `GitDependencyContractTest` | A write path in `git/`, an internal or removed platform API, a mis-declared optional dependency. |
| `TranscriptCapContractTest` | The host cap and the page cap drifting apart. |
| `SecretStoreIsolationContractTest` | A test JVM reaching a real credential store. |

## Conventions here

- **Every fixed bug leaves a regression test, and it is written red first.** A test that has never failed has
  not been shown to test anything.
- **Zero flakiness.** An unstable test is fixed or deleted, never retried.
- A test may construct an `internal` declaration from `src/main` — the test source set sees them. **That is
  why a `@TestOnly` wrapper living in `src/main` is a smell**: it is a second door onto something the test
  can already reach, and it reads as dead code to the reachability gate.
- **A top-level `private` in Kotlin is file-private and invisible to the test source set.** Demoting a symbol
  to silence the reachability gate breaks its tests instead.
- Contract tests scan **sources**, not bytecode, when the defect is one the compiler does not see.

## Minefields here

- **The reachability gate does not see a symbol used only inside a string template.** Its reduction step
  keeps the template's expressions — an interpolated call is a call — so the identifier survives and the use
  is never flagged. A symbol that looks orphaned and compiles into an HTML or JSON template is the case to
  check by hand before deleting anything.
- **Never trust `build/test-results/`.** It is the output of whichever run happened last, on whichever tree
  that was. Re-run the gate; do not read its XML as the current state.
- **Two parsers of the same sources will disagree eventually.** The map generator deliberately reuses this
  package's Kotlin dialect rather than inventing a second one.
- The integration layer starts a **real session**, which means a real launch. The credential vault refuses to
  touch a real home from a test JVM for exactly that reason; that guard is load-bearing, not defensive.
- `bin/fake-claude` is the contract for the integration layer. A protocol change that the stand-in does not
  model produces a green suite and a broken plugin.
