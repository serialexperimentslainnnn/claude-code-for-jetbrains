## What lives here

The wire, and nothing else: the shape of every message that crosses stdio between the plugin and the `claude`
binary, the parser that turns NDJSON into typed events, and the builders for the frames the plugin sends back.

**This package has no IDE dependencies, deliberately.** That is what lets it unit-test on a plain JVM with no
platform runtime, and it is a constraint to preserve — an `import com.intellij.…` here costs the whole
package its cheap test layer.

The protocol's own reference is the vendored SDK under `node_modules/@anthropic-ai/claude-agent-sdk/`
(`sdk.d.ts`, `sdk-tools.d.ts`, `sdk.mjs`), kept for its types and shipped to nobody. Where the SDK and the
binary disagree, **the binary wins**: the SDK types the requests and not always the replies.

## Conventions here

- **No IDE dependencies.** See above; this is the package's defining constraint.
- **Decoders are tables, not branches.** A new event registers a row; it never adds an `if` to the parser.
- **Model the field, do not guess it.** Verify a reply's shape against the binary itself — `strings` on the
  executable, or its own consumer code — rather than against the SDK's request types.
- Every subtype the plugin knows about, including the ones it deliberately never sends, is triaged into
  `ProtocolSurface.KNOWN_SUBTYPES` in the test tree. An untriaged subtype turns `checkDrift` red, which is the
  point: it is how a protocol change becomes visible instead of becoming a silent no-op.
- Field names follow the binary's own spelling. Where a field has arrived in both camelCase and snake_case at
  different versions, **read both** — a reply that silently decodes to zero is indistinguishable from a
  genuine zero.

## Minefields here

- **A lenient `Json` decodes an unexpected payload "successfully" into all defaults.** That is how a context
  meter once read 0%. Any decode that feeds a user-visible number must reject a reply that carries none of the
  fields it cares about, rather than returning a confident zero. `Asks.CONTEXT_USAGE` in `session/ControlAsks.kt`
  is the worked example.
- **Outbound builders here are not the catalogue any more.** Host→binary requests are declared as `Ask`s in
  `session/ControlAsks.kt`; a builder added here without a caller is dead on arrival, and this package is where
  the largest batch of unreachable code in the repository accumulated.
- **KDoc must not contain a literal `/*`** — Kotlin block comments nest, and this package's KDoc quotes wire
  fragments constantly.
- `system/init` arrives **every turn** and reports the launch-time `permissionMode`. Never block on it, and
  never adopt its mode.
